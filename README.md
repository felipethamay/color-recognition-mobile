# Color Recognition Mobile 🌈

Um app desenvolvido em React Native que utiliza técnicas de reconhecimento de cores por meio de redes neurais.

## 🚀 Tecnologias Utilizadas

- **React Native**: Framework para desenvolvimento de aplicativos móveis.
- **Expo**: Ferramenta para criar e gerenciar aplicativos React Native com facilidade.

## 📦 Requisitos

- **Node.js**: Versão `20.10.0` ou superior.

## ⚙️ Instruções de Execução

Para executar o aplicativo, siga os passos abaixo:

### 1. Clone o repositório
```bash
git clone https://github.com/seu-usuario/color-recognition-mobile.git
cd color-recognition-mobile
```

### 2. Instale as dependências
```bash
npm install
```

### 3. Execute o aplicativo

#### Para abrir no emulador Android:
```bash
npm run android
```

#### Para abrir no emulador iOS (se estiver usando um Mac):
```bash
npm run ios
```

#### Para abrir no navegador web:
```bash
npm run web
```

#### Ou apenas inicie o Expo no modo de desenvolvimento:
```bash
npm start
```
